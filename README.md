# INFORME-DE-VENTAS-EXCEL
Dashboard ejecutivo e informe interactivo de ventas en Microsoft Excel utilizando Tablas Dinámicas, segmentación de datos y análisis multidimensional por región, categoría de producto y rendimiento comercial.
